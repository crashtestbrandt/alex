# Glossary

The words the app, the caregiver guide and the docs use, and what each means in Alex.

| Term | Meaning |
| --- | --- |
| Learner | The child using the app. Nothing on their screen tests, scores, times or rewards them. |
| Caregiver | A parent or clinician. Every adult screen is theirs and sits behind caregiver mode. |
| Caregiver mode | The adults' screens. Three fingers held on the screen for three seconds open it. |
| Gestalt | A whole phrase the learner uses or an adult models, stored as heard. The unit of language here. |
| Chunk | One part of a gestalt, such as "outside" in "Let's go outside". |
| Mitigation | Recombining chunks of known gestalts into new phrases. Build is made for it. |
| Echolalia | Repeating heard speech. Treated as communication and never corrected. |
| Gestalt language processor | A child who acquires language in whole gestalts before single words. |
| NLA stage | A scene's place in the Natural Language Acquisition framework, set by a caregiver where the scene is chosen. It picks which written phrase each object in the scene says. Shown nowhere on the learner's screen and never advances on its own. |
| Profile | One learner's configuration: name, look, bank, rooms, boards and recordings. |
| Bank | Every gestalt a profile holds. |
| Scene | A room and the phrases that go with it. A profile starts with one and adds others. |
| Room | An explorable 3D space of objects. |
| Spot | An object in a room: a kind, a reaction and the phrase it says. |
| Reaction | What a spot does when touched: bounce, open, glow, spin, wobble, grow. |
| Explore | The learner's room mode. |
| Words | The learner's phrase mode, in two parts: Palette and Build. |
| Palette | Every phrase in the bank as a tile. |
| Build | A strip the learner fills by tapping beginnings and endings. The chunks the bank says next carry a border. |
| Beginnings, endings | The first chunk of every phrase in the bank, and every later chunk, each once. |
| Views | Front, Top and Tilt. Each room offers its own. |
| Hold | A two-second press. It opens the recorder. |
| Take | One recording of a phrase in a caregiver's voice. Keep saves it and keeps the previous take. |
| Chunk take | A take of one chunk. It speaks in every phrase the chunk appears in and in Build. |
| Look | A style: colors, type size, motion, corners and the room's materials. |
| Chunk color | The color a chunk carries everywhere, decided by its words. It marks the chunk and never judges it. |
